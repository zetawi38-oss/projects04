## Event Lifecycle
The theme switcher demonstrates the JavaScript event lifecycle:

1. User action: The user clicks the theme button.
2. Event firing: The browser fires the click event.
3. JavaScript callback: The registered event listener runs.
4. DOM/CSS mutation: JavaScript toggles the `dark-theme` class on the body element, and CSS updates the page colors.
